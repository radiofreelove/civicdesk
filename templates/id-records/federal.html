2026 passport sex-marker rules & risk before applying

Under Executive Order 14168, new, renewed, and name-updated U.S. passports print sex assigned at birth, and the X marker is no longer issued. Existing unexpired passports—including those with an updated M, F, or X marker—remain valid for travel until they expire or are replaced. {{ src('ID-US-EO-14168') }} {{ src('ID-US-STATE-SEX-MARKER') }} {{ src('ID-US-HRC-PASSPORT') }}

{% call m.box('watch', 'Read before mailing an existing passport with a matching marker') %}

ACLU and HRC warn that any passport application—even a Form DS-5504 or DS-82 submitted solely for a name change—can return with sex assigned at birth, and federal agencies can check older records. If your current unexpired passport has the marker you want, weigh whether you need a new passport now and consult legal counsel first. {{ src('ID-US-ACLU-ORR') }} {{ src('ID-US-HRC-PASSPORT') }} {{ src('ID-US-STATE-SEX-MARKER') }} {{ m.badge('our_reading') }}

Social Security (free name updates & NUMIDENT rules)

Request a free replacement Social Security card after marriage, divorce, or a court order ({{ ext('ID-US-SSA-NAME') }})—and update SSA before your state DMV so electronic name verification matches. {{ src('ID-US-SSA-NAME') }} {{ src('ID-OR-DMV-GENDER') }}

Social Security cards never print a sex marker. Under POMS RM 10212.200 (revised June 5, 2026, following the Jan. 31, 2025 directive), SSA restricts internal NUMIDENT sex-field edits to recording sex at birth and requires amendment proof alongside any amended birth certificate. {{ src('ID-US-SSA-POMS-10212-200') }} {{ src('ID-US-HRC-PASSPORT') }}

What still works at the state level

  • Oregon & Washington licenses and birth records continue offering M, F, or X (Oregon, Washington). {{ src('ID-OR-DMV-GENDER') }} {{ src('ID-WA-DOL-GENDER') }}
  • State courts in Oregon, Washington, and Utah continue granting legal name changes (compare the three states).
