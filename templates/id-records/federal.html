Social Security (NUMIDENT & name updates)

Legal name changes work normally ({{ ext('ID-US-SSA-NAME') }}, {{ src('ID-US-SSA-NAME') }}), and Social Security cards never display a sex marker. Under POMS RM 10212.200 (revised June 5, 2026, following the Jan. 31, 2025 directive), SSA only changes the internal sex field to record sex at birth and requires amendment proof with any amended birth record. {{ src('ID-US-SSA-POMS-10212-200') }} {{ src('ID-OR-DMV-GENDER') }} {{ src('ID-US-HRC-PASSPORT') }}
