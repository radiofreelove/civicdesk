Court steps for adults

The same process covers a name change, a legal sex change, or both without a lawyer. {{ src('ID-OR-OJD-ADULT-PACKET') }}

    {% call m.step('oregon', 1, 'or-step-forms', first_step) %}

    Use {{ ext('ID-OR-OJD-GUIDE-FILE') }} (free online interview in English, {{ src('ID-OR-OJD-GUIDE-FILE') }}) or print the {{ ext('ID-OR-OJD-ADULT-PACKET') }}. All adult and minor packets are on the {{ ext('ID-OR-OJD-FORMS') }}.

    {% endcall %} {% call m.step('oregon', 2, 'or-step-fill', 'Fill out the petition and judgment') %}
    • Check name, legal sex (male, female, or nonbinary—printed as X on Oregon IDs/birth records), or both, and list prior names.
    • For a sex change, check the attestation box ("surgical, hormonal, or other treatment appropriate to me"); Oregon law leaves what is appropriate to you with no doctor's letter or notary. {{ src('ID-OR-ORS-33') }}
    • Answer the "public interest" questions (child support owed, protective orders, probation/parole, sex-offender registration); a "yes" does not automatically mean denial. {{ m.badge('our_reading') }}
    {% endcall %} {% call m.step('oregon', 3, 'or-step-file', 'File it at a circuit court') %}

    Name only: file in your home county's circuit court. Sex, or name + sex: file in any Oregon circuit court ({{ ext('ID-OR-OJD-COURTS') }}). Pay {{ fact('or_fee_petition') }} or submit a {{ ext('ID-OR-OJD-FEE-WAIVER') }}.

    {% endcall %} {% call m.step('oregon', 4, 'or-step-wait', 'Wait for the judge') %}

    You usually do not appear in court unless the court mails a hearing notice. {{ src('ID-OR-OJD-ADULT-PACKET') }}

    {% endcall %} {% call m.step('oregon', 5, 'or-step-judgment', 'Get your judgment and certified copies') %}

    Once entered, the court mails a Notice of Entry of Judgment. Call the clerk to order certified copies ({{ fact('or_fee_certified_copy') }}). {{ src('ID-OR-OJD-FEES') }}

    {% endcall %} {% call m.step('oregon', 6, 'or-step-update', 'Update your records yourself') %}

    Take certified copies to Social Security first (if your name changed), then Oregon DMV and other offices. {{ src('ID-OR-OJD-ADULT-PACKET') }} Open the after-court checklist.

    {% endcall %}

Who can see your case {{ m.badge('changed') }}

{% call m.callout('changed', 'New in 2026: sex change cases are confidential', 'or-confidential') %}

Cases filed on or after {{ fact('or_confidential_date') }} that request a legal sex change (including combined name + sex petitions) are confidential—visible only to you, your lawyer, the court, someone allowed for good cause, and required minor-notice recipients. Pre-July 2026 filers can move for confidentiality, and name-only cases remain public unless sealed via Oregon's Address Confidentiality Program. {{ src('ID-OR-2026-CH52') }} {{ src('ID-OR-ORS-33') }}

Good questions

{% call m.qa("Do I need a doctor's letter or proof of surgery?", 'q-doctor') %}

No medical records or surgery are required; you check the box attesting to "surgical, hormonal or other treatment" appropriate for you. {{ src('ID-OR-ORS-33') }} {{ src('ID-OR-OJD-ADULT-PACKET') }}

{% endcall %} {% call m.qa("I don't live in Oregon. Can I file here?", 'q-out-of-state') %}

Name changes must be filed in the Oregon county where you live ({{ src('ID-OR-ORS-33') }}). For legal sex changes, the statute says "any circuit court in this state" without stating a residency rule—consult a lawyer before relying on out-of-state filing. {{ m.badge('our_reading') }}

{% endcall %} {% call m.qa("What will the judge decide?", 'q-judge') %}

Oregon law says the court "shall" grant a name or sex change unless it is "not consistent with the public interest." {{ m.badge('our_reading') }} {{ src('ID-OR-ORS-33') }}

{% endcall %} {% call m.qa("I filed before July 1, 2026. Is my old case public?", 'q-old-case') %}

It may be; for sex-change cases filed before July 1, 2026, you can file a motion asking the court to make the file confidential. {{ src('ID-OR-2026-CH52') }}

{% endcall %} {% call m.qa("Will an Oregon judgment change my birth certificate from another state?", 'q-other-birth-state') %}

Each birth state sets its own vital-records rules; check your birth state with {{ ext('ID-US-CDC-W2W') }}.
