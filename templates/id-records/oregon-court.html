Adult filing checklist

Check off each step as you go without a lawyer. {{ src('ID-OR-OJD-ADULT-PACKET') }}

    {% call m.step('oregon', 1, 'or-step-forms', 'Get the forms') %}

    Use {{ ext('ID-OR-OJD-GUIDE-FILE') }} (a free online interview in English) or print the {{ ext('ID-OR-OJD-ADULT-PACKET') }}. All adult and minor packets are on the {{ ext('ID-OR-OJD-FORMS') }}.

    {% endcall %} {% call m.step('oregon', 2, 'or-step-fill', 'Complete the petition and general judgment') %}
    • Check name, legal sex (male, female, or nonbinary—printed as X on Oregon IDs/birth records), or both, and list prior names.
    • For a sex change, check the attestation box ("surgical, hormonal, or other treatment appropriate to me"); Oregon law leaves what is appropriate to you. {{ src('ID-OR-ORS-33') }}
    • Answer the "public interest" questions (child support owed, protective orders, probation/parole, sex-offender registration); a "yes" does not automatically mean denial. {{ m.badge('our_reading') }}
    {% endcall %} {% call m.step('oregon', 3, 'or-step-file', 'File at circuit court') %}

    Name only: file in your home county's circuit court. Sex, or name + sex: file in any Oregon circuit court ({{ ext('ID-OR-OJD-COURTS') }}), attaching your fee or {{ ext('ID-OR-OJD-FEE-WAIVER') }}.

    {% endcall %} {% call m.step('oregon', 4, 'or-step-judgment', 'Order certified copies & update agencies') %}

    When your Notice of Entry of Judgment arrives in the mail, call the clerk to purchase certified copies, then update Social Security first (if your name changed) before visiting Oregon DMV. Open the after-court checklist.

    {% endcall %}

Good questions

{% call m.qa("Do I need a doctor's letter or proof of surgery?", 'q-doctor') %}

No medical records or surgery are required; you check the box attesting to "surgical, hormonal or other treatment" appropriate for you. {{ src('ID-OR-ORS-33') }} {{ src('ID-OR-OJD-ADULT-PACKET') }}

{% endcall %} {% call m.qa("I don't live in Oregon. Can I file here?", 'q-out-of-state') %}

Name changes must be filed in the Oregon county where you live. For legal sex changes, the statute says "any circuit court in this state" without stating a residency rule—consult a lawyer before relying on out-of-state filing. {{ m.badge('our_reading') }} {{ src('ID-OR-ORS-33') }}

{% endcall %} {% call m.qa("What will the judge decide?", 'q-judge') %}

Oregon law says the court "shall" grant a name or sex change unless it is "not consistent with the public interest." {{ m.badge('our_reading') }} {{ src('ID-OR-ORS-33') }}

{% endcall %} {% call m.qa("I filed before July 1, 2026. Is my old case public?", 'q-old-case') %}

It may be; for sex-change cases filed before July 1, 2026, you can file a motion asking the court to make the file confidential. {{ src('ID-OR-2026-CH52') }}

{% endcall %} {% call m.qa("Will an Oregon judgment change my birth certificate from another state?", 'q-other-birth-state') %}

Each birth state sets its own vital-records rules; check your birth state with {{ ext('ID-US-CDC-W2W') }}.
