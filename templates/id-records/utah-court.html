Who can see your case

Sex-designation petitions (including combined name + sex) keep filed papers private ({{ ext('ID-UT-COURTS-NONPUBLIC') }}), while case history and public hearings stay public; name-only cases appear public. {{ m.badge('our_reading') }} {{ src('ID-UT-COURTS-SEX-CHANGE') }}

Changes for someone under 18

{% call m.deeper('Utah minor name-change & strict age 15.5+ sex-designation rules', 'ut-minors-details') %}
  • Minor name change: Filed in the county where the child lived 1+ year, with second-parent consent or formal service plus a hearing. {{ src('ID-UT-COURTS-MINOR-CHANGE') }}
  • Minor sex designation (Utah Code 26B-8-111): Prohibited under age 15 years and 6 months; requires custodial parent/guardian permission, a court-appointed guardian ad litem (paid by parent unless waived), parent notice, a closed hearing, clear-and-convincing best-interest + no-harm findings, and takes effect no earlier than age 16. {{ src('ID-UT-CODE-26B-8-111') }}

Good questions

{% call m.qa("What does \"involved in any kind of lawsuit\" mean for me?", 'q-lawsuit') %}

The statute does not define the phrase further—if you are a party to a divorce, custody, debt, or eviction case, consult a lawyer before filing. {{ src('ID-UT-CODE-26B-8-111') }} {{ m.badge('our_reading') }}

{% endcall %} {% call m.qa("Can I ask the court to use my pronouns?", 'q-pronouns') %}

Yes—Utah Courts provides a pronoun notice form: {{ ext('ID-UT-COURTS-PRONOUNS') }}.

{% endcall %} {% call m.qa("What if the judge says no?", 'q-denied') %}

You can appeal; Utah Courts recommends seeking legal advice ({{ ext('ID-UT-COURTS-LEGAL-HELP') }}). {{ src('ID-UT-COURTS-SEX-CHANGE') }}

{% endcall %} {% call m.qa("Could I file in another state instead?", 'q-other-state') %}

Name petitions normally require local residency, and Utah agencies may not accept an out-of-state sex-designation order—talk to a lawyer first (Oregon note). {{ m.badge('our_reading') }}
