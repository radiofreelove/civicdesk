Optional court order confirming gender & under-18 rules

Washington does not require a court order for WA licenses or birth records, though an optional gender-confirmation order ({{ ext('ID-WA-WLH-GENDER-ORDER') }}) can help with another birth state. {{ src('ID-WA-WLH-GENDER-ORDER') }}

{% call m.deeper('Changes for someone under 18 in Washington', 'wa-minors-details') %}
  • Name: A parent/guardian can file a child's name change (including sealed in superior court for gender identity/expression), with notice to parents and child consent often requested at age 13+. {{ src('ID-WA-RCW-4-24-130') }} {{ src('ID-WA-WLH-NAME') }}
  • Birth certificate: Use {{ ext('ID-WA-DOH-422-144') }} signed by a parent/guardian and licensed provider (WA birth record guide). {{ src('ID-WA-DOH-SEX') }}
{% endcall %}

Good questions

{% call m.qa("Do I have to file in the county where I live?", 'q-county') %}

No—Washington law allows filing a public name change in any district court or a sealed name change in any superior court statewide. {{ src('ID-WA-RCW-4-24-130') }}

{% endcall %} {% call m.qa("Who can see a sealed name change?", 'q-sealed') %}

No one in the public; the file opens only for you, your guardian/representative, or by court order for good cause. {{ src('ID-WA-RCW-4-24-130') }}
