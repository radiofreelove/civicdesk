Under 18

Use {{ ext('ID-WA-DOH-422-144') }} signed by a parent/guardian and a licensed provider. Watch out: DOH's sex-designation page still links the retired 422-034 for minor first/middle name changes without court—use the new Application to Amend a Birth Certificate on {{ ext('ID-WA-DOH-AMEND-BIRTH') }} instead, or send a minor court order with {{ ext('ID-WA-DOH-422-126') }}. {{ src('ID-WA-DOH-SEX') }} {{ src('ID-WA-DOH-AMEND-BIRTH') }}
