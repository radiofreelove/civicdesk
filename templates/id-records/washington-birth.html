How adults update a Washington birth certificate

  • Adults and emancipated minors sign {{ ext('ID-WA-DOH-422-143') }} in front of a notary to select M, F, or X (court orders and doctor letters are not accepted for sex designation). {{ src('ID-WA-DOH-SEX') }}
  • Also changing your name? Include a certified court order and {{ ext('ID-WA-DOH-422-126') }}. Amending is free; new certified copies cost {{ fact('wa_doh_cert_fee') }}.

Under 18

Use {{ ext('ID-WA-DOH-422-144') }} signed by a parent/guardian and a licensed provider ({{ src('ID-WA-DOH-SEX') }}). Watch out: DOH's sex-designation page still links the retired 422-034 for minor first/middle name changes without court—use the new Application to Amend a Birth Certificate on {{ ext('ID-WA-DOH-AMEND-BIRTH') }} instead, or send a minor court order with {{ ext('ID-WA-DOH-422-126') }}. {{ src('ID-WA-DOH-AMEND-BIRTH') }}
