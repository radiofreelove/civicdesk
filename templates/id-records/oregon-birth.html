Way 1: a notarized form, no court

  • Use {{ ext('ID-OR-OHA-2673') }} or {{ ext('ID-OR-OHA-2673-ES') }} to update name, sex (M, F, or X), or both once administratively (later changes require a court order). {{ src('ID-OR-OHA-GENDER') }}
  • Fill it out to match your current birth record, sign in front of a notary, and attach a photo ID copy (plus name-link proof if your ID shows a different name).
  • Pay {{ fact('or_oha_amend_fee') }} plus {{ fact('or_oha_cert_fee') }} (check/money order to "OHA/Vital Records"; expedite {{ fact('or_oha_expedite') }}). Mail to {{ m.copyable(fact('or_oha_mail'), 'mailing address') }} or use the drop box at {{ fact('or_oha_dropbox') }}.

Way 2: use your court judgment

Send a certified court judgment (Oregon or out-of-state) with the {{ fact('or_oha_amend_fee') }} amendment fee. Court-ordered name-only changes add an old-name footnote unless the court sealed the order. {{ src('ID-OR-OHA-GENDER') }} {{ src('ID-OR-OHA-COURT-ORDER') }}

{% call m.deeper('Certificate footnote rules & 2026 confidential court orders', 'or-birth-footnotes') %}
  • Administrative OHA 2673 footnotes: Changing sex (or name + sex) leaves zero change footnotes and removes old ones; changing name alone via OHA 2673 notes a name change without printing your prior name. Note that some outside agencies still ask for a court order. {{ src('ID-OR-OHA-GENDER') }}
  • 2026 confidential court cases: 2026 Oregon Laws ch. 52 (HB 4088) makes post-July 1, 2026 sex-change court files confidential, but we have not confirmed whether Vital Records treats them like sealed orders for footnotes. {{ src('ID-OR-2026-CH52') }} {{ m.badge('not_confirmed') }} Ask first: {{ m.copyable(fact('or_oha_email'), 'email address') }}
